# FAHAD KHAN — Portfolio Website

A responsive static portfolio website for Fahad Khan, Digital Marketing Professional.

## Files
- index.html — page structure and content
- style.css — complete responsive design
- script.js — mobile menu, scroll progress, reveal animations
- assets/fahad-khan.jpg — profile photo
- assets/Fahad-Khan-CV.docx — CV download

## GitHub Pages deployment
1. Create a GitHub account if you do not already have one.
2. Create a PUBLIC repository named `FAHAD-KHAN`.
3. Upload all files and folders from this project.
4. Open Settings → Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select branch `main` and folder `/ (root)`, then Save.
7. Your live URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/FAHAD-KHAN/`

Important: the URL cannot be controlled by the repository name alone. It always contains your GitHub username. If your GitHub username is `fahadkhan`, the cleanest URL is:
`https://fahadkhan.github.io/FAHAD-KHAN/`

If you want the URL itself to be exactly `https://fahadkhan.github.io/`, create the repository named `fahadkhan.github.io` and upload the site to that repository.
